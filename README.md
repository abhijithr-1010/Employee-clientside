# Employee Dashboard (MERN Assignment 2)

React app built with Vite, React Router and Bootstrap.

## Features
- Navbar with **Home** and **Employee Form** links
- Home page lists users from https://jsonplaceholder.typicode.com/users (id, name, email) as cards, with search
- Employee Form with Name, Designation, Location, Salary (validated, no POST)
- Routes: `/` and `/employee-form`, plus a 404 page

## Run
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build
```bash
npm run build
```
